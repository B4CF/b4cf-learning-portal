How to Add Content

All content is managed directly in your Google Sheet. No coding needed.

📋 Content Library sheet — add videos & articles:
Columns: ID | Type | Title | URL | Category | Duration | Description
Type must be video or article

📝 Quiz Questions sheet — add quiz questions:
Columns: Quiz ID | Content ID | Question | Option A | Option B | Option C | Option D | Correct | Points
Correct column: enter A, B, C, or D

After adding content, students see it immediately when they open the portal.

Google Apps Script URL

One-time setup (5 minutes):
1. Open your Google Spreadsheet
2. Click Extensions → Apps Script
3. Paste the backend .gs code, save (Ctrl+S)
4. Click Deploy → New Deployment
5. Type: Web app  |  Execute as: Me  |  Access: Anyone
6. Click Deploy → copy the /exec URL
7. Paste it below and click Save
